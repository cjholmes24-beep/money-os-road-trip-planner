# Homepage visual assets

`assets/travel-coast.svg` is original vector artwork created for this repository: a fictional coastal landscape, road, village, aircraft, luggage and passport. It illustrates travel; it is not a photograph, destination claim, booking listing or live travel offer.

Source: original project artwork, drawn directly as SVG for this redesign. No third-party stock asset or external license is used or required. The inline line icons and CSS card art are likewise original project artwork. No third-party logo, font, image API, hotlink or attribution requirement is introduced.

The 3,559-byte illustration scales to different screens without a large raster download. It has fixed dimensions to reserve layout space, a descriptive text alternative, no script or external references, and responsive cropping. Inline decorative icons are hidden from assistive technology. The color palette uses sea green, warm peach and a dark premium base.

Review screenshots are produced by `tests/browser-homepage-smoke.js` at 360, 390, 412, 768 and 1440 pixels. CI retains these as the `homepage-viewport-screenshots` artifact. All smoke-test external requests are blocked, so tests do not run affiliate scripts, generate provider clicks or contact Google.
